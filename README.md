# FitLog

## 📝 Short Description
FitLog is a dark, no-nonsense gym companion app that allows users to browse a library of workouts, view detailed instructions, and log their daily routines. It helps track total exercises, durations, and calories for the day with a cap of five lifts.

## 🛠️ Technologies Used
- Next.js (App Router)
- React (Hooks, Context API)
- Tailwind CSS
- Lucide React (Icons)
- React Toastify (Notifications)

## ✨ 5 Key Features of the Project
1. **Interactive Workout Library:** Browse a responsive grid of workouts loaded from the API, displaying key details like duration, calories, and rating.
2. **Dynamic Sorting:** Easily sort the workout library by Duration, Calories, or Rating to find the perfect exercise.
3. **Detailed Workout Views:** Dedicated pages for each exercise detailing equipment, difficulty, sets, reps, and step-by-step instructions.
4. **Daily Plan & Bookmarks:** Add up to 5 exercises to "Today's Plan" or bookmark them to "Saved", with live badge counters in the navigation bar.
5. **Actionable Logs & Live Metrics:** Track total exercises, minutes, and calories dynamically based on the active tab. Mark exercises as "Done" or remove them with real-time toast notifications.
